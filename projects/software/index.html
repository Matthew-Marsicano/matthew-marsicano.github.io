Backscatter Designer

Interactive RF Design Tool

October 2026

  • Browser tool for N-phase backscatter tag design: bistatic link budget, Smith chart load states, image rejection, sideband spectrum with BLE channels marked, and coverage maps.
  • Loads can be ideal phasors with injected error or arbitrary R + jX per state.
  • All parameters live in the URL, so a design can be shared as a link. Plain JavaScript and Plotly, no build step.
